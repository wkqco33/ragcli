## Build

### Option 1: Using vcpkg (Manifest Mode)

1. Set `VCPKG_ROOT` environment variable to your vcpkg installation path.
2. Use the `debug` or `release` presets which automatically use the vcpkg toolchain:

```bash
export VCPKG_ROOT=/path/to/your/vcpkg  # Important!
cmake --preset debug
cmake --build --preset debug
```

### Option 2: System Libraries (Native)

If you have dependencies installed via system package manager (apt, dnf, etc.):

```bash
cmake --preset debug-native
cmake --build --preset debug-native
```

## Test
